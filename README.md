# 현 — 노블레스 수현 × 결정사·데이트 하이브리드 서비스 (제휴 제안)

노블레스 수현(isoohyun.co.kr) 정회원 매칭과 데이트 앱을 한 앱에 담는 하이브리드 서비스 제휴 제안.

- **역할:** 노블레스 수현 = 고객 DB · 운영 · 홍보 / 제품 측 = 기획 · 디자인 · 앱·웹·어드민 제작
- **수익 배분(제안):** 제품 2 : 노블레스 수현 8 — 앱 결제 순매출 + 앱 유입 정회원 가입비(상담 예약 후 90일 내 가입) 기준

## 자료
- 기획서 (Claude Docs): https://claude.ai/artifact/CUvgmJ1ff9g2v6TYki42eA
- 디자인 캔버스: https://claude.ai/artifact/VioCoK3czRRzqnG5G7sEGR
  - 윗줄 — 앱 화면 9개, 플로우 순서: ① 가입·데이트 (시작 → 추천·매치 → 대화) ② 이벤트 (라운지 → 신청 → 오늘의 질문 → 내 정보·BASIC+) ③ 정회원 전환 (매니저 상담 → 정회원 홈)
  - 아랫줄 — 웹 소개 랜딩 · 제휴 기획서 · BASIC 데이트 회원 & 앱 이벤트 기획

- 둘 다 비공개 — 미팅 전 Share 메뉴로 공유

## 현재 상태 (2026-10-30)
- 디자인 방향: Porcelain & Onyx Clay — 클레이모피즘 · 아이소메트릭 · 키네틱 타이포, 샴페인 골드 포인트
- 데이트 앱 구조: 스와이프 추천 덱 · 매치 · 대화방 · 이벤트 라운지 · BASIC+ 구독 · 미션 리워드
- 사진 원칙: 앱의 모든 데이트 사진은 3D 애니메이션 스타일로 변환된 이미지만 노출, 원본은 인증팀만 열람 — 실제 얼굴은 만나서
- BASIC 회원 단계(BASIC · 인증+ · BASIC+)와 이벤트 8종 기획 (가격·횟수는 `[ ]`로 미정)
